# Koshava

Пилот онлайн-заказа продуктов из Lidl Srbija с курьерской доставкой по Белграду. Задача пилота — проверить гипотезу: будут ли люди заказывать продукты Lidl онлайн при доставке за 10% от суммы и минимальном заказе 5 000 дин.

Интерфейс на русском и сербском (латиница), переключатель в шапке. Оплата при получении, онлайн-эквайринга нет.

## Что умеет

| Раздел | Возможности |
|---|---|
| Каталог | 25 категорий из официального прайс-листа, акции с датами, сортировка, поиск (понимает русские слова: «молоко» → mleko) |
| Карточка товара | Фото, описание, цена, цена за кг/л, сроки акции, штрихкод, похожие товары |
| Корзина | Работает без регистрации; после входа гостевая корзина переносится в аккаунт. Шаг для весовых товаров — 0,5 кг |
| Избранное | Работает без регистрации, тоже переносится при входе |
| Оформление | Сумма товаров от 5 000 до 30 000 дин., доставка 10%, один выезд курьера в день в 10:00 начиная со следующего дня, городской район Белграда из списка (10 общин), оплата наличными или картой курьеру. Замен нет: отсутствующий товар не доставляется и не оплачивается |
| Профиль | Имя, телефон, сохранённые адреса, история и статусы заказов |
| Регистрация | Email и пароль, открытая; восстановления пароля пока нет |
| Политика конфиденциальности | `/privacy` на двух языках, ссылка в подвале и в форме регистрации; контакт из `CONTACT_EMAIL` |
| Админка `/admin` | Заказы со сменой статуса и заметкой оператора, метрики пилота (заказы, выручка, средний чек, корзины), состояние импорта |

## Архитектура

| Слой | Технология | Почему |
|---|---|---|
| Приложение | Next.js 16 (App Router, Server Actions), TypeScript, Tailwind CSS 4 | Один репозиторий для фронта и бэкенда, SSR, бесплатный хостинг на Vercel |
| База данных | PostgreSQL + Drizzle ORM | Supabase/Neon на бесплатном тарифе; без привязки к вендору |
| Авторизация | Своя: bcrypt + сессии в базе, httpOnly cookie | Без внешних сервисов; легко заменить на Supabase Auth / OAuth |
| Поиск | Postgres `pg_trgm` + нормализация (кириллица → латиница, диакритика) + словарь RU→SR | Хватает на ~3 000 товаров; дальше — Meilisearch/Typesense |
| Данные | Скрипты импорта; GitHub Actions запускает их вручную, расписание включается одной строкой | Для пилота хватает разовой выгрузки; обновление без своего сервера |
| Тесты | Vitest (разбор прайса, поиск, доставка), Playwright (сценарий заказа, desktop и mobile) | |

```
src/
  app/[locale]/     страницы (ru, sr): каталог, товар, корзина, оформление, профиль, админка
  actions/          server actions: корзина, избранное, вход, заказ, админка
  lib/              доступ к данным, корзина, поиск, доставка, импорт
  i18n/             словари ru/sr
  db/schema.ts      схема базы
scripts/            миграции и импорт
drizzle/            SQL-миграции
e2e/, tests/        тесты
```

## Откуда данные

| Данные | Источник | Как связаны |
|---|---|---|
| Цены, акции, категории, штрихкоды | [cene_proizvoda_Lidl.csv](https://www.lidl.rs/explore/assets/webPriceData/rs/cene_proizvoda_Lidl.csv), официальный прайс-лист Lidl Srbija (обязателен по закону, зеркало на [data.gov.rs](https://data.gov.rs/sr/datasets/cenovnici-proizvoda-prema-pravilniku-o-uslovima-sadrzaju-i-nacinu-objavljivanja-cenovnika-lidl/)) | Основа каталога, около 3 100 товаров |
| Дополнительные штрихкоды | [EAN.csv](https://www.lidl.rs/explore/assets/webPriceData/rs/EAN.csv) | Расширяют поиск фото |
| Фото и описания | Библиотека lidl.rs (см. ниже): превью каждого товара, когда-либо опубликованного на lidl.rs | Точное совпадение по штрихкоду (GTIN), в том числе по прошлым штрихкодам товара |
| Фото (если нет на lidl.rs) | [maxi.rs](https://www.maxi.rs), затем [Open Food Facts](https://world.openfoodfacts.org) / Open Beauty Facts / Open Products Facts (CC BY-SA) | Точное совпадение по штрихкоду через поиск maxi.rs и выгрузки OFF; на карточке пометка «Фото ознакомительное» |

На сайте весь прайс-лист: товары без фото показываются с заглушкой, фото из Open Food Facts помечены тегом «Фото ознакомительное» (на карточке и странице товара). `PUBLISH_WITHOUT_IMAGE=false` оставляет только товары с фото; настройка применяется при импорте.

Ответы источников кэшируются в таблице `content_cache`: повторный запуск запрашивает только новые товары. Ненайденные штрихкоды перепроверяются раз в 30 дней.

API Open Food Facts на практике отдаёт около 15 ответов в минуту, поэтому первичная загрузка идёт через их ежедневные выгрузки (`import:dumps`), а API используется только для новых товаров.

Lidl Srbija выкладывает на lidl.rs не весь ассортимент, а около 500 товаров с ограниченным сроком: акции недели, сезонные и непродовольственные товары «U prodavnici od … do …». Поэтому основная часть фото приходит из Open Food Facts и maxi.rs. Порядок выбора: lidl.rs → maxi.rs → Open Food Facts.

### Библиотека lidl.rs

Товары исчезают с lidl.rs вместе с фото, когда заканчивается акция, поэтому Koshava хранит собственную копию (`npm run import:lidl`, workflow **Lidl library**).

Когда обновляется lidl.rs:

| Что | Когда |
|---|---|
| Редакция публикует новые товары (сразу видны в поиске сайта) | По будням в рабочие часы, за 2–7 дней до начала акции |
| Карта сайта пересобирается (одновременно для всех стран Lidl) | Раз в сутки, около 23:05 UTC (00:05 по Белграду зимой) |
| Акции начинаются в магазинах | По понедельникам и четвергам |

Поэтому workflow запускается каждый час по будням с 07:17 до 17:17 по Белграду (зимнее время; летом на час позже) и каждую ночь в 23:37 UTC, после пересборки карты сайта. Запуск без новостей длится около минуты и в журнал импорта не попадает.

- список товаров — из карты сайта `https://www.lidl.rs/static/sitemap.xml` (раздел `/p/export/`) и из поиска сайта (`/q/api/search?q=*`), где товары появляются раньше, чем в карте сайта; страницы, ответившие 404, не запрашиваются повторно неделю;
- новые страницы и страницы старше 7 дней перечитываются: название, бренд, штрихкоды, описание, ссылки на все фото, история цен и сроков акции (`lidl_library`);
- превью (первое фото) сохраняется в базе в WebP до 600 px, в среднем 15 КБ (`lidl_images`), отдаётся через `/api/img/<id>`; `LIDL_LIBRARY_IMAGES=3` сохранит и фото галереи;
- товары, которых больше нет на lidl.rs, не удаляются, а помечаются `removed_at`; фото остаются и подходят товарам прайс-листа по любому из штрихкодов;
- просмотр — Админка → «Библиотека Lidl».

500 МБ бесплатной базы Supabase хватает примерно на 25 000 превью (каталог и кэши занимают ещё 40–60 МБ); если понадобится больше — файлы можно перенести в Supabase Storage или Cloudflare R2. Фото принадлежат Lidl; использовать их публично стоит только с согласия правообладателя.

Товар определяется по названию из прайс-листа, а не по штрихкоду: Lidl каждый день подставляет к одному названию штрихкод другого варианта (вкуса, поставщика). Все штрихкоды, которые были у товара, сохраняются и используются для поиска фото. Повторяющиеся названия (например, два вида яблок по разной цене) нумеруются.

Мелкие категории прайс-листа (меньше ~30 товаров) объединены с близкими — `src/lib/import/categories.ts`. «Rasprodaja» — виртуальная категория со всеми товарами со скидкой.

## Локальный запуск

Нужны Node.js 22+ и PostgreSQL: локальный (`docker compose up -d`) или облачный (Supabase).

```bash
cp .env.example .env.local      # указать DATABASE_URL и свой email в ADMIN_EMAILS
npm install
npm run db:migrate              # создать таблицы
npm run import:prices           # загрузить прайс-лист (~30 с)
npm run import:dumps            # фото из выгрузок Open Food Facts (~1,5 ГБ потоком, 10–15 мин)
npm run import:lidl             # библиотека lidl.rs: превью всех товаров с сайта (первый раз ~20 мин)
npm run import:content          # фото из библиотеки и точечные запросы к API для оставшихся (~15 мин)
npm run import:maxi             # фото с maxi.rs вместо фото из Open Food Facts (~15 мин)
npm run dev                     # http://localhost:3000
```

Админ: зарегистрируйтесь с email из `ADMIN_EMAILS`, ссылка «Админка» появится в шапке и в профиле.

Правила пилота (суммы, доставка, шаг веса, районы) — в `src/config/shop.ts`.

Проверки:

```bash
npm run typecheck && npm run lint && npm test
npm run test:e2e                # при запущенном npm run dev; в ADMIN_EMAILS должен быть admin@koshava.test
```

## Бесплатный деплой

Всё ниже бесплатно и нужно только для публичной ссылки. Локально сайт работает и без этого.

### 1. Supabase (база данных)

1. [supabase.com](https://supabase.com) → Start your project → вход через GitHub.
2. New project: имя `koshava`, придумать и сохранить пароль базы, регион **Central EU (Frankfurt)**, тариф Free.
3. Через 1–2 минуты нажать **Connect** вверху страницы проекта и скопировать две строки подключения, подставив пароль вместо `[YOUR-PASSWORD]`:
   - **Session pooler** (порт 5432) — для миграций и импорта;
   - **Transaction pooler** (порт 6543) — для сайта на Vercel.

Таблицы закрыты от REST API Supabase миграцией `0001_enable_rls` (RLS без политик); сайт подключается напрямую к Postgres и этого не замечает.

### 2. Загрузка данных

Вариант A — через GitHub Actions, пароль никуда не передаётся:

1. Репозиторий → Settings → Secrets and variables → Actions → New repository secret: `DATABASE_URL` = строка **Session pooler**.
2. Actions → Import Lidl price list → Run workflow (mode: full). Занимает 30–40 минут: миграции, прайс-лист, библиотека lidl.rs, фото из выгрузок Open Food Facts и maxi.rs. Дальше workflow **Lidl library** сам пополняет библиотеку: каждый час по будням и каждую ночь.

Вариант B — локально с той же строкой: `DATABASE_URL=... npm run db:migrate && npm run import:prices && npm run import:lidl && npm run import:dumps && npm run import:content`.

### 3. Vercel (хостинг)

1. [vercel.com](https://vercel.com) → Sign Up → Hobby → вход через GitHub.
2. Add New → Project → Import рядом с `koshava`. Если репозитория нет в списке: Adjust GitHub App Permissions → дать доступ к `koshava`.
3. Framework Preset определится сам (Next.js). В Environment Variables добавить:
   - `DATABASE_URL` — строка **Transaction pooler** (6543);
   - `ADMIN_EMAILS` — email администратора;
   - `CONTACT_EMAIL` — контакт для страницы политики конфиденциальности.
4. Deploy — 1–2 минуты. Адрес вида `koshava.vercel.app`; поменять можно в Settings → Domains.
5. Зарегистрироваться на сайте с email из `ADMIN_EMAILS` — появится ссылка «Админка».

Функции работают во Франкфурте (`vercel.json`), рядом с базой. Каждый push в `main` деплоится автоматически.

Ограничения бесплатных тарифов: Supabase Free ставит проект на паузу после 7 дней без запросов (снимается в панели одной кнопкой), 500 МБ базы. Vercel Hobby предназначен для некоммерческого использования; для запуска с реальными заказами нужен Pro ($20/мес.).
